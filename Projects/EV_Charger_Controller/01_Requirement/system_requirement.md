# EV Charger Controller System Requirement

## Project

AI Smart EV Charger Controller


## Objective

Design an intelligent embedded controller for DC fast charging station.


## Target

Power Range:

50kW - 150kW DC Fast Charger


## Input

AC Grid:
- Three Phase
- Industrial Power Input


## Output

DC Charging Control


## Controller

Main MCU:

STM32H7 Family


## Communication

Required interfaces:

- CAN Bus
- Ethernet
- RS485
- USB


## Vehicle Communication

Support:

- CCS2
- GB/T


## Cloud

Support:

- OCPP Protocol


## Sensors

Monitoring:

- Voltage
- Current
- Temperature
- Isolation


## Requirements

- Industrial reliability
- Modular architecture
- Secure firmware
- Remote monitoring
